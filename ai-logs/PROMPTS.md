# Prompt log

**Optional** if you export your full chat history (see `HOW-TO-EXPORT.md`); the export already
contains your prompts. Use this file when you cannot export a full transcript, or to highlight
the key prompts.

If you do use it: log every meaningful prompt you send the AI, in order. One `##` entry per
prompt. Keep it flowing as you work. Delete the TEMPLATE entry below before submitting.

Format:

## TEMPLATE - short title of the prompt
- **When:** (rough time or commit)
- **Tool/model:** (e.g. Claude Code / Opus, Cursor / GPT-5)
- **Prompt:** what you asked (paste it or summarize faithfully)
- **What the AI gave / what I did:** did you accept it, edit it, reject it, re-prompt? Why?
